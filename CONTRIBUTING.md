# Contributing

Please use issues for bug reports and platform requests. Include Zotero version, macOS/Windows version, browser/version, the failing phase from `status.log`, and precise reproduction steps. **Redact PDF titles, local file paths, and unpublished content. Never include ChatGPT cookies or tokens.**

Changes to UI automation should be tested on a fresh conversation and should never automatically press Send without an explicit product redesign and opt-in.

Before proposing new platforms, split PDF/SI extraction from browser-specific upload logic; do not make the existing Safari path conditional on unverified Windows behavior.
